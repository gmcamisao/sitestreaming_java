# Screen Match (sitestreaming_java)

Projeto de estudo em Java com o tema de um site de streaming de filmes, o **Screen Match**. Cada classe pratica um conceito básico da linguagem.

## O que tem no projeto

| Classe | Conceito praticado |
|---|---|
| `Main` | Variáveis, tipos primitivos, `String`, text blocks, cálculo de média e conversão (`cast`) |
| `Condicional` | Estruturas `if/else` e operadores lógicos (`&&`) |
| `Leitura` | Leitura de dados do usuário com `Scanner` |
| `Loop` | Laço `for` para calcular a média de 3 notas |
| `OutroLoop` | Laço `while` com sentinela (`-1` encerra a leitura) |

## Como executar

Requisitos: **JDK** instalado (versão com suporte a `static void main` sem `public`, ver observação abaixo).

1. Clone o repositório:
   ```bash
   git clone https://github.com/gmcamisao/sitestreaming_java.git
   ```
2. Abra a pasta no **IntelliJ IDEA**.
3. Execute a classe desejada (por exemplo `Main`) pelo botão de play ao lado do método `main`.
